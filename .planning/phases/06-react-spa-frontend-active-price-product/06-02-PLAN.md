<objective>
Build the two pure presentation components that render already-computed price and trend values: `TrendBadge` (color-coded 7d/30d percent change, muted dash for insufficient data — PRICE-03) and `PriceDisplay` (total-led headline with always-visible item-price secondary line — PRICE-01, D-05). Both are dumb formatters over the exact API contract; neither recomputes anything.

Purpose: These are the reused building blocks that `ProductRow` (06-05) and `ProductDetailPage` (06-06) compose. Isolating them lets their behavior be unit-tested against the four trend states and the null-safe price shape before composition.
Output: Two tested, reusable components plus their CSS modules using the design tokens.
</objective>
