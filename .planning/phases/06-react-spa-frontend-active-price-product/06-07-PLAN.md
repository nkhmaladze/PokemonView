## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| React SPA → Flask API | Route loaders fetch `/products` and `/products/:id` cross-origin (dev proxy) / same-origin (prod) |
| API error → error boundary | A rejected loader (404/500) is surfaced to the route errorElement |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-06-03 | Spoofing | dev proxy / CORS | low | accept | The dev proxy targets localhost:5001; production CORS is enforced server-side (Phase 5 CR-02, scoped to r"/products*"). This plan introduces no CORS-bypass proxy and calls only the two allowed paths |
| T-06-01 | Tampering / Information Disclosure | ProductNotFound / error render | low | mitigate | The error boundary renders only fixed literal copy plus (optionally) the thrown Error's own message via JSX text interpolation — no raw-HTML rendering of error content (V5) |
</threat_model>
