<objective>
Put the all-time range on the page: a new full-width block between the trend row
and the price history chart, carrying its verbatim qualifying caption and the
`AllTimeRangeBadge` built in Plan 09-02, plus the page-level tests that prove all
four badges survive a product with no data at all.

Purpose: the range's number is the easy part. The load-bearing part is the
caption — without the parenthetical scoping it to our own collection window, a
user reasonably reads "all-time high" as a market record for the product, which
it is not and cannot be from a few weeks of four-hourly snapshots. This plan
treats that string as a contract, not as copy.

Output: the rendered section, its stylesheet rule, and the page tests that pin
the caption, the ordering and the zero-data state.
</objective>

<threat_model>
## Trust Boundaries

No new trust boundary is introduced by this plan. It renders values already
crossing the `Flask API → browser` boundary documented for Phase 8; it opens no
network path, adds no fetch and installs no package.

| Boundary | Description |
|----------|-------------|
| API JSON → DOM | `all_time_range.high`, `all_time_range.low` and `trend_24h.pct_change`, all database-sourced numbers, become badge text on the detail page |

## STRIDE Threat Register

ASVS level 1; blocking severity `high`. Per `09-RESEARCH.md`'s Security Domain
section, V2/V3/V4/V6 do not apply and V5 is trivially satisfied — this plan adds
no input surface, no new route parameter and no new request.

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-09-05 | Tampering | DB-sourced price numbers rendered as badge text on `ProductDetailPage` | low | mitigate | Both bounds are formatted inside `AllTimeRangeBadge` and handed to React as text children, which escape by default; the page adds no `dangerouslySetInnerHTML`, sets no attribute from a database value, and builds no markup from strings |
| T-09-08 | Information Disclosure | a mislabelled range implying a market-wide or completed-sale price record | low | mitigate | The qualifying caption is locked verbatim by `09-UI-SPEC.md` D-UI-02, rendered as visible page text rather than a tooltip, and asserted as a whole string by a test with a demonstrated failing mutation — a shortened label cannot ship silently |
| T-09-09 | Denial of Service | render cost of the new section | low | accept | The section renders one caption and one two-value badge regardless of how much history a product has accumulated; there is no per-point cost here, unlike the sibling chart's accepted `AR-08-03` |
| T-09-SC | Tampering | package-manager installs | low | accept | This plan installs zero packages; `frontend/package.json` gains no dependency, so no install-time code-execution surface is introduced |

## Canon referral

Query-operator injection through `product_id`, generic information-disclosure
hardening and dependency-supply-chain review are canon concerns already owned by
`/gsd-secure-phase` and the per-plan threat registers above; they are not minted
as bespoke prohibitions in this phase's `must_haves`.
</threat_model>
