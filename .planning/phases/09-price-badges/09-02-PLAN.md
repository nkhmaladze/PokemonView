<objective>
Build the one genuinely new component this phase needs: a two-state presentational
badge that renders a product's all-time low and high total price as a single
chip, or an explicit muted dash when there is nothing to show.

Purpose: the existing `TrendBadge` is shaped around a signed percent with a
four-state up/down/flat/insufficient convention. An all-time range is two
absolute dollar values with no direction, so forcing it through `TrendBadge`
would mean overloading that component's prop shape — a worse outcome than one
small sibling that follows the identical status-first discipline. This plan
delivers that sibling and pins every state it can be in before anything renders
it.

Output: `AllTimeRangeBadge.jsx`, its CSS module, and its test file.
</objective>

no input surface of any kind.
