Output: `scripts/ebay_client.py`, `scripts/verify_ebay_access.py`.

  <action>
    Create `scripts/ebay_client.py` with three functions and no top-level execution:

    - `get_app_token(env: str = "production") -> dict` — reads `EBAY_CLIENT_ID` and `EBAY_CLIENT_SECRET` from `os.environ` (never hardcoded, D-02); base64-encodes `client_id:client_secret` for HTTP Basic auth; POSTs `grant_type=client_credentials` with `scope=https://api.ebay.com/oauth/api_scope` to `https://{host}/identity/v1/oauth2/token` where host is `api.ebay.com` for production and `api.sandbox.ebay.com` for sandbox; sets `Content-Type: application/x-www-form-urlencoded` and the `Authorization: Basic ...` header; uses a 15s timeout; calls `raise_for_status()`; returns the parsed JSON (`access_token`, `expires_in`, `token_type`). Do NOT build a token cache / retry / refresh wrapper (that is Phase 3's job) and do NOT expect a refresh_token (client-credentials returns none).
    - `search_sealed_listings(access_token: str, query: str, limit: int = 50) -> list[dict]` — GETs `https://api.ebay.com/buy/browse/v1/item_summary/search` with `Authorization: Bearer {access_token}` and `X-EBAY-C-MARKETPLACE-ID: EBAY_US`; params `q=query`, `filter=conditions:{NEW}`, `limit=limit`; 15s timeout; `raise_for_status()`; returns `json()["itemSummaries"]` (default to empty list if absent). Use keyword-only search (no category_ids) — per Assumption A2 / Open Question 2 no sealed-product category ID is confirmed; record whatever `categoryId` real responses report rather than filtering on one.
    - `total_cost(item: dict) -> float` — returns `float(item["price"]["value"]) + shipping`, where shipping is `float(shippingOptions[0]["shippingCost"]["value"])` when the `shippingOptions` array is non-empty, else `0.0`.

    Credential/secret hygiene (threat T-01-02): the module must never `print`/log the full `access_token` or the base64 Basic-auth string. If any diagnostic is emitted, restrict it to `token_type` and `expires_in`. Read `EBAY_CLIENT_ID`/`EBAY_CLIENT_SECRET` exclusively from `os.environ`.
  </action>
