## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| developer machine → PyPI | `pip install` downloads requests + python-dotenv (supply-chain surface) |
| `.env` → script process | Real Production OAuth secrets are read into the process at run time; must never be logged or committed |
| script → eBay Production API | Outbound authenticated Browse call; response data written to a committed fixtures file (titles + price/shipping only, no seller PII) |

</threat_model>
