<objective>
Author the three deployment-config artifacts that make the repo deployable to Fly.io as one image / two always-on process types (D-01/D-02/D-03): a single-stage Dockerfile, a .dockerignore that keeps secrets out of the build context, and a fly.toml declaring the web (gunicorn) and worker (APScheduler) process groups with scale-to-zero explicitly disabled.
