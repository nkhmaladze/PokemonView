## Spacing Scale

Declared values (must be multiples of 4) — inherited unchanged from `tokens.css` / `06-UI-SPEC.md`:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline padding, badge padding |
| sm | 8px | Compact element spacing, badge padding |
| md | 16px | Default element spacing, page padding |
| lg | 24px | Section gaps (`.detail` flex gap) |
| xl | 32px | Layout gaps |
| 2xl | 48px | Major section breaks |
| 3xl | 64px | Page-level top padding |

Exceptions for this phase:

- **Chart container height: `280px`** (fixed, not a spacing token — matches `tokens.css`'s existing convention of documented one-off fixed sizes like `--size-thumbnail-detail: 96px`). Applies identically to all three chart-section states (loading / insufficient-history / populated) so switching between them never causes a layout shift. Divisible by 4 (280 = 70 × 4), consistent with the project's "multiples of 4" spacing discipline even though it is a fixed size, not a scale token.
- The new "Price History" section sits inside `.detail`'s existing `gap: var(--space-lg)` flex column — no new outer spacing value needed; it is simply the next child after `.detail__trendSection`.

## Typography

Inherited unchanged from `tokens.css` / `06-UI-SPEC.md` — no new sizes or weights introduced this phase.

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Label | 12px | 400 (regular) | 1.5 |
| Body | 14px | 400 (regular) | 1.5 |
| Heading | 18px | 600 (semibold) | 1.2 |
| Display | 28px | 600 (semibold) | 1.2 |

Applied to this phase's new elements:

- **"Price History" section heading** (D-03): reuses the **Heading** role (18px / 600 / 1.2) — same tier as `.detail__title`, but **without** the accent-color bottom border (that treatment is reserved for the page's single `<h1>` title; see Color below). Do not invent a new "subheading" tier.
- **Chart axis tick labels & tooltip text**: reuse the **Label** role (12px / 400 / 1.5) — matches `.trendLabel`/`.detail__badge`'s existing caption tier. Recharts' `XAxis`/`YAxis`/`Tooltip` font-size should be set to `var(--font-size-label)` explicitly (Recharts defaults to a slightly different size than this project's scale).
- **Insufficient-history / loading / error inline messages**: reuse the **Body** role (14px / 400 / 1.5) — matches `.detail__noData`'s sibling pattern for "no data" strings, but at Body size (not Display size) since this is a secondary chart-section message, not the page's primary price headline.
- **Tooltip price value**: apply `.tabular-nums` (existing utility class) so digits align, matching every other price rendering in the app (`PriceDisplay`, `TrendBadge`).

## Color

Inherited unchanged from `tokens.css` — no new color tokens introduced. One **addition to the accent's reserved-for list** (below).

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#0B0D12` (`--color-bg`) | Page background (unchanged) |
| Secondary (30%) | `#171A21` (`--color-surface`) / `#232833` (`--color-divider`) | Tooltip background (`--color-surface`); chart gridlines and hairline dividers (`--color-divider`) — **new use of `--color-divider` for `CartesianGrid` stroke, consistent with its existing "hairline divider" role** |
| Accent (10%) | `#E8A33D` (`--color-accent`) | See reserved-for list below — **new addition: the price-history line stroke** |
| Destructive | `#D92D20` (`--color-destructive`) | Reserved, unused this phase — no destructive actions exist on this page |

**Accent reserved for** (explicit list — `tokens.css`'s existing comment plus this phase's one addition):

- Active filter-chip background (`FilterChips`, unchanged)
- Focus ring (unchanged)
- Links — e.g. the `← Back to catalog` link (unchanged)
- Page-title (`<h1>`) bottom-border underline (unchanged)
- **NEW: the Price History chart's single `<Line>` stroke** — the one accent-colored visual element in the chart, deliberately not colored by up/down direction (that convention is reserved for `TrendBadge`'s `--trend-up`/`--trend-down`/`--trend-flat` semantic colors, which do not apply here — this chart shows the raw total-price series, not a percent change)

**Executor note:** update the `tokens.css` file-header comment / `--color-accent` inline comment to add "price-history chart line" to its documented reserved-for list when this phase lands, so the contract stays traceable in the token file itself (matching how `--trend-*` tokens already cite their consuming component).

## Layout Notes (phase-specific, supplementary)

- **Placement (D-03):** the new "Price History" section is appended to `ProductDetailPage.jsx` immediately **after** `.detail__trendSection` (7d/30d badges) and **before** `.detail__meta` (MSRP/release date) — preserving the page's existing top-to-bottom order: header → price → trends → **history (new)** → meta.
- **Section structure:** a `<section>` (or `<div>`) with the "Price History" heading, followed by the fixed-280px-height chart container that hosts exactly one of: loading text, insufficient-history text, error text, or the Recharts `LineChart`. Never render more than one of these four at once, and never leave the container height unset (prevents layout jump between states).
- **Chart composition (D-01):** `ResponsiveContainer` → `LineChart` → `CartesianGrid` (dashed, `--color-divider`) + `XAxis` (date ticks, `--text-secondary`, Label-size font) + `YAxis` (`$` price ticks, `--text-secondary`, Label-size font) + `Tooltip` (`--color-surface` background, formatted date + `$X.XX` value) + `Line` (`--color-accent` stroke, `dot={false}`, `activeDot={{ r: 4 }}`, `type="monotone"`) — exact composition specified in `08-RESEARCH.md` Pattern 3; this UI-SPEC's job is only to confirm the token mapping (done above), not to re-derive the component tree.
- **No range selector, no toggle:** per D-02/D-05 and REQUIREMENTS.md's Out-of-Scope table — this phase renders the full raw series with zero interactive chrome beyond the built-in tooltip. Do not add 7d/30d/All buttons or an item/total price toggle.
