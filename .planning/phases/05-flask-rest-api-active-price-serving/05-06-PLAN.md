## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| client→API (HTTP request: query params, path param, method) | Untrusted user input crosses into the Flask app at the route boundary |
| API→client (JSON success + error responses) | Responses must not leak internals (stack traces); CORS governs which origins may read them |
| create_app → MongoDB | The single MongoClient is built inside the factory using MONGODB_URI (never logged), read-only usage |

Verified by test_product_type_enum_validation |

Verified by test_error_handler_no_traceback |
