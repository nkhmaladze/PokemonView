<objective>
Build the two controlled input components that drive live, client-side catalog filtering (SEARCH-01): `SearchBar` (free-text input, instant onChange — D-12/D-14) and `FilterChips` (single-select-per-group `product_type` and `set_name` toggle chips — D-13 plus the discretionary set chip). Both are presentational/controlled — they own no fetch and no product data; `CatalogPage` (06-05) owns the filter state and applies it in-memory.

Purpose: Splitting the interactive controls from the list page keeps each component small and independently testable (typing behavior, chip toggling) before wiring into the page.
Output: Two tested controlled components with their CSS modules.
</objective>
